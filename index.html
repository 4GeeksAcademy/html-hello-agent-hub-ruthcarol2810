¿Qué es una Skill en AgentHub?

Una skill es una capacidad modular que se puede añadir a un agente para ampliar las tareas que puede realizar (por ejemplo, navegar por la web, leer documentos PDF, o sincronizarse con calendarios corporativos). Permiten componer agentes a medida para cada necesidad empresarial.
